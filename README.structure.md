# agimind · 仓库目录说明

> 原根目录 README。文章索引见 [README.md](./README.md)。

用来整理自己学习 AGI 思路的个人项目。记录思路、灵感，以及平时收集的有价值信息。

## 目录结构

### `thoughts/` — 系统性思路

按主题分文件，存放经过整理、相对完整的思考。

示例文件名：

- `agi-path.md` — 对 AGI 实现路径的思考
- `architecture.md` — 架构与设计相关
- `open-questions.md` — 尚未想通的问题

### `sparks/` — 灵感碎片

随时记录突然冒出的想法，一条灵感一个文件，不必写长。

文件名建议：

- `2026-08-31-短标题.md`
- 或任意能唤起记忆的名字

### `notes/` — 信息摘录

外部信息摘录与自己的注释。建议每篇包含：

- **来源**：链接、作者、日期
- **摘录**：原文或摘要
- **我的想法**：为什么记录、与已有思路的关联

### `resources/` — 参考索引

链接、书单、论文索引。可按类型分子文件，例如：

- `papers.md` — 论文
- `books.md` — 书籍
- `links.md` — 文章、视频、工具

### `deployments/` — 可复现实验脚本

与 `notes/` 中的实践文档配套的部署脚本、benchmark 结果等。**不含模型权重**。

示例：

- `flagos-qwen38-m5/` — FlagOS + Qwen3.8-27B Mac M5 CPU 推理脚本

## 使用方式

- 有完整想法 → 放进 `thoughts/`
- 突然冒出的点子 → 放进 `sparks/`
- 读到的好内容 → 摘录到 `notes/`
- 值得收藏的参考 → 汇总到 `resources/`
